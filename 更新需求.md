# 首页入场与爆炸动画效果

## 背景

现在音符按钮和切歌按钮是对齐的，但是暂停之后，暂停键比切歌按钮高了，你调整一下。然后我想把显示歌名和歌手的的艺术字改成google fonts的Dancing Script。而且现在暂停键好像只对一首歌有效，当这首歌的时长播完之后，就会开始恢复播放新的一首歌。还有歌曲名滚动播放的时候不是左右摇摆滚动，是一直向左滚动，然后在左边界消失，从右边界重新显现的这种循环效果。



## 球

新上传的照片可以随机出现在照片球的某个位置，不一定要严格按照上传顺序排列

# 主界面

新增照片模块时点击保存的时候反应有点慢，导致有些用户可能看没反应就多点几次，导致重复上传。这个延迟反应是可以解决的吗？如果必须要等一会才能上传完成，那么在等待上传的时候可以在上传按钮上显示一个转圈圈的动态，表示正在上传。

这个云数据库最多可以储存多少张照片




## Supabase Storage -> Cloudflare R2 migration

The migration script is intentionally conservative:

- It always exports Supabase rows to `memories-before.json`.
- It writes a `migration-plan.json` before changing anything.
- It downloads old media files into the backup folder unless `--skip-media-backup` is passed.
- It does not delete old Supabase Storage objects.
- It updates Supabase only when `--write` is explicitly passed.
- It writes R2 objects to `images/<memory-id>-<filename>` by default, without nested folders under `images/`.

Required values for a real migration:

```bash
export R2_ACCESS_KEY_ID="..."
export R2_SECRET_ACCESS_KEY="..."
export R2_PUBLIC_BASE_URL="https://your-public-r2-domain.example.com"
export SUPABASE_SERVICE_ROLE_KEY="..."
```

`R2_PUBLIC_BASE_URL` must be a browser-readable public URL, such as an R2 public `r2.dev` domain or a custom domain. It is not the S3 API endpoint.

Your R2 account and bucket are already the script defaults:

```bash
R2_ACCOUNT_ID=128598718da0d76f8893b3836f1785ff
R2_BUCKET=jjn-ug-memo
R2_ENDPOINT=https://128598718da0d76f8893b3836f1785ff.r2.cloudflarestorage.com
```

Backup/dry run:

```bash
python3 scripts/migrate_supabase_storage_to_r2.py --backup-only
```

Real migration:

```bash
python3 scripts/migrate_supabase_storage_to_r2.py --write
```

Re-run from an existing backup without re-downloading Supabase Storage:

```bash
python3 scripts/migrate_supabase_storage_to_r2.py --write \
  --source-backup backups/supabase-r2-20260531T092336Z \
  --skip-media-backup
```
